# GameBay Platform Contract (Runtime API v3 snapshot)

This note summarizes the platform contract observed in the GameBay game SDK and developer docs when this repository was created. It is a convenience reference, not an authoritative API specification. Verify current signatures and host behavior before implementing or publishing.

## Package and runtime

- A GPK is a ZIP-based package containing an entry HTML file, local JavaScript/CSS/assets, and a manifest generated by the packer.
- Games run locally in an Android TV WebView; assume no network access. Keep all dependencies in the package and use relative local paths.
- Current game projects use `gamebay.json` with `runtimeApiVersion: 3`, a unique alphabetically sorted `capabilities` array, and a matching `<meta name="gamebay-capabilities" content="...">` tag.
- The game repository's packer is authoritative for allowed paths, file count, archive size, required metadata, hashes, and capability cross-checks.

## Runtime APIs to verify in the current SDK

The current SDK exposes the following families when declared:

| Capability | API family |
| --- | --- |
| `input` | `gb.onInput(...)`, `gb.input.state(player)` |
| `players` | `gb.players.list()`, `gb.players.onChange(...)` |
| `audio` | `gb.audio.create(localPath)`, `gb.audio.tone(...)` |
| `lifecycle` | `gb.onLifecycle(...)` |
| `storage` | Per-game local key-value storage with quotas |
| `save` | `gb.save.load()`, `write(data)`, `clear()` |
| `checkpoint`, `launch` | Resumable checkpoints and host continue/new decision |
| `haptics` | Player/controller vibration API, if host supports it |
| `exit` | Host exit route, when explicitly permitted |
| `log` | `gb.log(...)` to host diagnostics |

Exact method shapes, limits, events, and dependencies between capabilities can change. Read `sdk/runtime.js`, the manifest validator, and Android host code from the current repositories.

## Input ownership and compatibility

- TV remote D-pad and OK are primary. Host-reserved Back/B is used for pause/navigation and may not be delivered to the game.
- For multiplayer and bound controllers, use GameBay player state instead of identifying physical devices yourself.
- Do not assume a controller button mapping across all hardware. The host contract and actual Android TV tests determine support.
- Every held action must have a release/reset path, including pause, focus loss, restart, and player disconnect.
- `input` event repeat semantics can differ between browser preview and Android TV; implement game-specific repeat/timing as needed and verify on device.

## Save and security boundaries

- Treat local storage as untrusted input: validate shapes, ranges, and schema versions before restoring.
- Keep checkpoints small and write at intentional safe points; avoid synchronous writes every animation frame.
- Local saves are not cloud saves and may disappear when app data is cleared or the app is uninstalled.
- GPK code and assets are client-delivered and can be extracted. Hashes and sandbox restrictions help detect corruption and limit APIs; they are not DRM or copy protection.
- Do not put credentials, private server settings, personal data, or hidden admin endpoints in a GPK or public game source.
